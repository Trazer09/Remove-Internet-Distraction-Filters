# RID - Remove Internet Distraction Filters

**Get RID of distractions.**

uBlock Origin filters for YouTube, Instagram, Reddit, and Google Search.

*Originally created as Remove YouTube Distraction, now expanded into RID Filters.*

## Browser Extension

**Want an easier way to block distractions?**

Try **[Remove Internet Distraction for Firefox](https://addons.mozilla.org/en-US/firefox/addon/remove-internet-distraction/)** for a less distracting browsing experience.

- **[Install from Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/remove-internet-distraction/)** — Official Firefox Add-ons store.
- **[View Source Code on GitHub](https://github.com/Trazer09/Remove-Internet-Distraction)** — Open source.
- **Feedback welcome!** Report bugs or suggest features through [GitHub Issues](https://github.com/Trazer09/Remove-Internet-Distraction/issues).

## Installation

1. Install [uBlock Origin](https://github.com/gorhill/uBlock).
2. Copy your chosen filter list into **My Filters** and click **Apply Changes**.

### YouTube
- [`youtube.txt`](./youtube.txt) — Recommended
- [`youtube-strict.txt`](./youtube-strict.txt) — More aggressive filtering

### Instagram
- [`instagram.txt`](./instagram.txt) — Remove distractions

### Reddit
- [`reddit.txt`](./reddit.txt) — Remove distractions

### Google Search — Remove AI Mode
- [`google-ai.txt`](./google-ai.txt) — Remove Google AI search elements

*Google may change its layout, causing filters to stop working.*
